# Ateira MiniMBA

Рабочий MVP образовательного приложения для дизайнеров, переходящих к продуктовым и управленческим задачам.

## Требования

Для работы требуется Docker с поддержкой Docker Compose. Локальные Node.js и npm не используются.

## Запуск

```powershell
docker compose up --build
```

После успешного запуска откройте `http://localhost:4173`.

Остановка:

```powershell
docker compose down
```

## Тесты

Все проверки запускаются только внутри Docker:

```powershell
docker compose --profile test run --rm test
```

Команда проверяет синтаксис серверного и клиентского JavaScript, затем запускает smoke-тест страницы, health API и демонстрационного AI.

## OpenRouter

Без ключа AI-наставник работает в демонстрационном режиме. Для реальных ответов скопируйте `.env.example` в `.env`, укажите значения и пересоберите контейнер:

```powershell
Copy-Item .env.example .env
docker compose up --build
```

Если `OPENROUTER_MODEL` не задан, используется модель по умолчанию из настроек OpenRouter. Ключ хранится только на сервере и не передаётся в браузер.

## Демо-доступ

- Код бесплатного доступа: `ATEIRA-DEMO`
- До активации пользователю доступен один урок после онбординга.
- Монетизация и платёжная форма в MVP намеренно не подключены.

## Учебные материалы

В интерактивный урок встроен блок скачивания дополнительных материалов первых двух занятий:

- рабочая тетрадь участника;
- руководство преподавателя;
- презентации «Бизнес как система» и «Стратегия как набор выборов».

Файлы находятся в `public/materials/first_lessons` и раздаются тем же статическим сервером.

## Хранение данных

В прототипе профиль и учебный прогресс хранятся в `localStorage` браузера. Перед публичным запуском их необходимо перенести в серверную базу данных, добавить полноценную аутентификацию, журнал согласий и процедуры экспорта/удаления данных для запуска в ОАЭ.

## Правило проекта

Корневой файл `AGENTS.md` запрещает запуск приложения и тестов напрямую на хосте. Если Docker недоступен, локальный runtime не используется как запасной вариант.
