# Промпты для учебных аниме-видео Ateira MiniMBA

Комплект содержит 14 самостоятельных промптов: 12 недель действующего маршрута и два вводных блока из новых учебных материалов.

## Как использовать

1. Откройте `00_STYLE_BIBLE.md` и сохраните референсы персонажей в генераторе как постоянные character references.
2. Выберите файл нужного блока и передайте его видеогенератору целиком.
3. Если инструмент создаёт только короткие клипы, генерируйте каждую сцену отдельно по указанным таймкодам, затем собирайте их в монтажной программе.
4. Дикторскую дорожку лучше генерировать отдельно по разделу «Дикторский текст», а экранный текст добавлять на монтаже. Так русские надписи будут без ошибок.
5. Перед публикацией проверьте финансовые формулы, валюту, произношение терминов и отсутствие случайных логотипов.

## Формат результата

- 16:9, 1920×1080, 24 fps;
- длительность 90–120 секунд;
- русский диктор, спокойный деловой тон;
- оригинальная аниме-эстетика без подражания конкретным художникам, студиям или франшизам;
- субтитры и ключевые формулы добавляются отдельным текстовым слоем;
- один ролик объясняет одну управленческую идею и заканчивается вопросом или действием.

## Файлы

- `01–12` — действующие недели MiniMBA;
- `13` — «Бизнес как система»;
- `14` — «Стратегия как набор выборов»;
- `00_PROMPT_TEMPLATE.md` — шаблон для следующих уроков.
