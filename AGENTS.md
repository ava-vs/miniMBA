# Обязательные правила проекта

## Запуск и тестирование

- Приложение всегда запускается только в Docker через `docker compose`.
- Все тесты, проверки синтаксиса, линтеры, миграции и другие исполняемые проверки всегда запускаются только внутри Docker-контейнеров.
- Запрещено запускать `node`, `npm`, `pnpm` или другие runtime-команды проекта напрямую на хостовой системе.
- Для запуска приложения используется `docker compose up --build`.
- Для запуска полного набора проверок используется `docker compose --profile test run --rm test`.
- Для остановки приложения используется `docker compose down`.
- Если Docker недоступен, нельзя незаметно переходить на локальный runtime. Нужно сообщить, что запуск или проверка заблокированы отсутствием Docker.

Эти правила распространяются на разработчиков и AI-агентов, работающих в данном проекте.
